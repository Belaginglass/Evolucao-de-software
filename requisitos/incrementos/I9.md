# Incremento 9 — Apadrinhamento de animais e causas

**Casos de uso:** UC007 (Apadrinhamento de causa) e UC008 (Apadrinhamento de animal)

> Fonte: *Requisitos_e_Casos_de_Uso.pdf*, seção 6, p. 50-59.

## UC007 — Apadrinhamento de causa

**Descrição:** o sistema deve disponibilizar ao usuário um link para que ele possa se informar sobre os projetos de causas mantidos pela ONG.

**Atores:** Diretor geral.

**Precondições:** Deve haver projetos cadastrados no sistema.

**Pós-condições:** Abrir outra janela para um site externo com mais informações sobre o projeto.

### Fluxo Básico
1. Ator acessa `[PRT-3]` e clica em qualquer botão "saiba mais".
2. Sistema abre, em outra janela, o link cadastrado pelo Diretor geral, levando a uma página externa do projeto.

*(Não há fluxo alternativo, fluxo de exceção, nem protótipo de tela dedicados a este UC, conforme o documento original.)*

## UC008 — Apadrinhamento de animal

**Descrição:** o sistema deve oferecer um meio de o ator apadrinhar um animal, seja por meio de serviço ou apoio financeiro.

**Atores:** Adotante.

**Precondições:** Não há.

**Pós-condições:** Um novo pedido de prestação de serviço poderá ser enviado, ou geração de boleto mensal ou pontual.

### Fluxo Básico
1. Ator acessa a página de apadrinhamento pelo menu, ou via `[FA-15]`.
2. Sistema retorna `[PRT-24]`.
3. Se clicar nas "setas", exibe outros serviços ocultos; se clicar "Doar" → `[FA-16]`; se clicar "Veja todas as prestações de serviço" → retorna `[PRT-26]`; se clicar "selecionar" em um serviço → segue o fluxo básico.
4. Sistema verifica autenticação; se não autenticado, redireciona para `[PRT-1]` e, após autenticar, retorna `[PRT-25]`; se já autenticado, retorna `[PRT-25]` direto.
5. Se clicar "x", fecha o modal retornando a `[PRT-24]`. Ator seleciona dia/horário e clica "adicionar horário".
6. Sistema cadastra os horários em uma lista.
7. Ator pode "apagar" um horário da lista; ao clicar "Salvar"...
8. Sistema salva o pedido de apadrinhamento no banco e adiciona notificação no menu dos gestores.

### Fluxo Alternativo — `[FA-15]` Acessando serviço da página inicial
1. Inicia quando o ator clica "selecionar" em um serviço listado em `[PRT-3]`.
2. Sistema prossegue direto para o passo 4 do fluxo básico.

### Fluxo Alternativo — `[FA-16]` Doação
1. Inicia ao clicar "doar" em `[PRT-24]`.
2. Sistema verifica autenticação; se não autenticado, exibe `[PRT-28]`.
3. Se clicar "entrar" → retorna `[PRT-1]`; se clicar "gerar boleto" → retorna `[PRT-29]`.
4. Ator preenche os campos e clica "gerar boleto".
5. Sistema abre o boleto em outra janela; se marcada a opção mensal, sistema gera e envia o boleto mensalmente por e-mail, incrementando o valor previsto de orçamento.

### Fluxo Alternativo — `[FA-17]` Reagendando prestação de serviço
1. Inicia quando o ator tem notificação de reagendamento e acessa `[PRT-24]`, clicando "clique aqui para saber mais".
2. Sistema retorna `[PRT-27]`.
3. Se o ator confirmar um dos horários propostos → sistema envia a confirmação ao gestor responsável e retorna a `[PRT-24]`.
4. Se o ator clicar "enviar proposta de horário" → sistema retorna `[PRT-30]`; ator preenche horários e clica "salvar"; sistema envia os horários ao gestor de adoção e retorna a `[PRT-24]` com mensagem de sucesso.

### Protótipos referenciados
`[PRT-24]` Opções de apadrinhamento · `[PRT-25]` Agendamento de horário · `[PRT-26]` Listagem de serviços já prestados · `[PRT-27]` Contraproposta de horário · `[PRT-28]` Gerar boleto/autenticar · `[PRT-29]` Dados para boleto · `[PRT-30]` Proposta de novo horário.

## Requisito Funcional relacionado (ambos os UCs)

**`<RF012>` Manter apadrinhamento**
> "O sistema deve permitir que o adotante possa apadrinhar um animal ou causa por exemplo: apadrinhar construção de baias, fisioterapia de animais, acupuntura, consulta clínica, ração, passeios e o animal propriamente dito."

**`<RN009>` Gerência de agendas** *(transversal — aqui aplica-se ao agendamento de prestação de serviço do UC008; ver `requisitos_transversais.md`)*
> "Cada animal deverá ter sua própria agenda, contudo essa agenda só deve ser criada quando o animal receber uma proposta de prestação de serviço [...]."
