# Incremento 3 — Cadastro e gerenciamento de animais

**Caso de uso:** UC003 — Cadastro de Animal

> Fonte: *Requisitos_e_Casos_de_Uso.pdf*, seção 6, p. 26-31.

## UC003 — Cadastro de Animal

**Descrição:** o sistema deve permitir o cadastro de animais, restrito a usuários com nível de acesso de Gestor de Adoção `[ATR-02]` (ou Diretor Geral `[ATR-01]`). O cadastro exige as informações expostas em `<RN003>`.

**Atores:** Gestor de adoção `[ATR-02]` e Diretor geral `[ATR-01]`.

**Precondições:** Estar autenticado no sistema e possuir privilégio para realizar essa atividade.

**Pós-condições:** Ao final, um novo registro de animal deve estar inserido no banco de dados.

### Fluxo Básico
1. Ator acessa a tela de cadastro de animais pelo menu administrativo.
2. Sistema retorna `[PRT-7]`.
3. Ator preenche o formulário. Se clicar "Cancelar" → `[FA-3]` (UC002); se "Adicionar foto" → `[FA-5]`; se "Cadastre outro" → `[FA-6]`; se usar o campo "pesquisar" → `[FA-7]`; se clicar "Salvar" → segue o fluxo básico.
4. Sistema valida as opções conforme a descrição do requisito; se inválidas → `[FE-1]` (UC002); se válidas, salva o novo registro e retorna `[PRT-12]`.

### Fluxo Alternativo — `[FA-5]` Adicionar Fotos
1. Inicia ao clicar em "Browser" em `[PRT-7]`.
2. Sistema exibe `[PRT-8]`, permitindo incorporar imagem do Instagram/rede social ou enviar imagem ao servidor.
3. Ao "anexar", incrementa um elemento na lista de imagens; ao "browser", abre janela de envio, exibindo a foto com opção de exclusão ("x"); "cancelar" fecha sem anexar; "concluir" continua o fluxo.
4. Sistema valida as imagens e anexa ao registro do animal; se houver problema → `[FE-1]` (UC002); senão retorna a `[PRT-7]`.

### Fluxo Alternativo — `[FA-6]` Cadastre outro
1. Inicia ao clicar em "Cadastre outro" em `[PRT-7]`.
2. Sistema valida as informações conforme `<RN003>`; se inválidas → `[FE-1]` (UC001); se válidas, salva em novo registro, recarrega `[PRT-7]` com mensagem de sucesso, e reinicia o fluxo básico.

### Fluxo Alternativo — `[FA-7]` Buscar raça
1. Inicia ao digitar no campo "pesquisar" em `[PRT-7]`.
2. Sistema filtra dinamicamente a lista de raças pelas letras digitadas.
3. Ator seleciona um ou mais elementos da lista.
4. Sistema adiciona os itens selecionados a uma lista com opção de exclusão por "x".

### Fluxo Alternativo — `[FA-8]` Cadastro de vacina
1. Inicia ao clicar em "adicionar nova" em `[PRT-7]`.
2. Sistema retorna `[PRT-9]`.
3. Ator pode editar o nome de uma vacina existente (clicando sobre o nome), excluir (botão "x"), ou criar uma nova vacina em linha nova da tabela. Ao clicar "cancelar" → `[FA-3]` (UC002). Ao clicar "salvar", sistema persiste as configurações de vacina e retorna a `[PRT-7]` com os registros atualizados no campo vacinas.

### Protótipos referenciados
`[PRT-7]` Cadastro de animal · `[PRT-8]` Envio de imagem · `[PRT-9]` Cadastro de vacina · `[PRT-12]` Pesquisa de animais (modo administrativo).

## Requisitos Funcionais relacionados

**`<RF002>` Cadastro de Animal (Manter animal)**
> "O sistema deverá oferecer um meio de cadastrar animais, este cadastro deverá ser realizado apenas por usuários que tenham nível de acesso compatível."

**`<RF008>` Manter baias**
> "O sistema deverá cadastrar, editar e atualizar informações referentes as baias dos animais. Cada baia possui um numero de identificação que é opcional e um nome que é obrigatório."

**`<RF014>` Manter vacinas**
> "O sistema deve oferecer uma forma de cadastrar vacinas e vincular essas vacinas ao registro do animal."

## Requisitos Não Funcionais relacionados

**`<RNF004>` Lista de raças**
> "O sistema deve exibir uma lista de raças durante o cadastro do animal e alterar a busca conforme a opção do ator, caso o ator esteja cadastrando um animal da espécie canina as raças deverão ser apenas de cães e o contrário para a espécie felina. Essa lista deverá exibir uma miniatura da foto da raça quando uma selecionada, para facilitar a escolha do ator."

**`<RNF006>` Autoria de material fotográfico**
> "Deverá haver um meio de identificar os autores das fotos dos animais. Na informação detalhada do animal deverá constar uma lista de fotógrafos que foram responsáveis pelas fotografias daquele animal. Além do nome deve-se se possível conter um link para contato do mesmo."

## Regra de Negócio relacionada

**`<RN003>` Informações do animal**
> "As seguintes informações são necessárias para cadastrar um animal: Espécie (Canina/Felina); Sexo (Macho/Fêmea); Castrado (Sim/Não); Vermifugado (Sim/Não); Idade aproximada; Raça; Temperamento (Dócil, Agressivo, Arisco, Bipolar, Não sociável com outros animais, Temperamental); Porte (Pequeno ≤10kg, Médio ≤25kg, Grande >25kg); Fotos (JPG, PNG e similares, incluindo Instagram/Facebook); Nome de referência; História; É um patrimônio tombado? (Sim/Não); Está em tratamento? (Sim/Não); Está disponível para adoção? (Sim/Não); Vacinas; Quantidade de doses de cada vacina; Data da aplicação de cada dose; Baia do animal; Outras informações; Autor da fotografia; Contato do autor. Todas as informações são obrigatórias, exceto: temperamento, idade aproximada, baia, porte, fotos e contato do autor. Deverá ser possível enviar n arquivos de imagem. [...] Sempre que um animal estiver classificado como patrimônio tombado o sistema deve automaticamente marcar 'não' para 'Está disponível para adoção?'; o mesmo para quando for marcado 'sim' para 'Está em tratamento?'. [...] O sistema deve fazer com que o ator informe quais são os autores das fotografias do animal e adicione seu contato, sempre que houver inserção de fotografias."
