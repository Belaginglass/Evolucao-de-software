# Incremento 4 — Página inicial e apresentação dos animais

**Caso de uso:** UC009 — Manter página inicial

> Fonte: *Requisitos_e_Casos_de_Uso.pdf*, seção 6, p. 59-64.

## UC009 — Manter página inicial

**Descrição:** o sistema deve prover um meio de o Diretor geral manter as campanhas, o texto informativo sobre a ONG e os serviços exibidos na página inicial.

**Atores:** Diretor geral e Gestor de adoção.

**Precondições:** Estar autenticado e autorizado.

**Pós-condições:** Criação, edição ou deleção de uma causa da ONG.

### Fluxo Básico
1. Ator acessa `[PRT-2]` e utiliza algum botão de edição de conteúdo. Se clicar em editar o texto "sobre nós" → sistema retorna `[PRT-31]`. Se clicar em editar serviços → `[PRT-32]`. Se clicar em editar campanhas → `[PRT-33]`. Se clicar em editar doações → `[PRT-34]`.
2. Ator preenche os campos da página de retorno. Se clicar "x", sistema fecha sem salvar e volta a `[PRT-2]`. Se clicar "adicionar nova opção" → `[FA-18]`.
3. Se o ator clicar "salvar", sistema salva as alterações no banco de dados e retorna a `[PRT-2]` com mensagem de sucesso.

### Fluxo Alternativo — `[FA-18]` Adicionar nova opção
1. Inicia ao clicar "adicionar nova opção" nos protótipos `[PRT-32]`, `[PRT-33]` ou `[PRT-34]`.
2. Sistema insere um novo modelo de campo para o ator criar mais uma opção de serviço, valor de doação ou campanha.
3. Ator preenche os campos e retorna ao fluxo básico.

### Protótipos referenciados
`[PRT-31]` Edição de texto informativo · `[PRT-32]` Edição de serviços · `[PRT-33]` Edição de campanhas · `[PRT-34]` Edição de valores para doação.

Não há um `<RFxxx>` numerado especificamente para "Manter página inicial" na seção 4 do documento original. A funcionalidade decorre do requisito de usuário listado na seção 2.2:
> "[ATR-01] Manter página inicial."

## Regra de Negócio relacionada

**`<RN010>` Escolha de dados na tela inicial do sistema**
> "Na tela inicial do sistema que pode ser vista nos protótipos [PRT-2] e [PRT-3] o sistema deverá escolher aleatoriamente os serviços, campanhas, valores para doação e animais a serem exibidos."

*(Esta regra também é citada no Incremento 1 / UC001, pois rege a lógica de exibição da página inicial imediatamente após o login — ver `requisitos_transversais.md`.)*

## Observações de fidelidade ao documento original
- O UC009 não possui fluxo de exceção descrito no documento original (apenas fluxo básico e um alternativo).
- A gestão de animais exibidos aleatoriamente na página inicial (parte do nome deste incremento) é regida pela mesma `<RN010>`, não havendo um fluxo de evento dedicado a animais dentro do UC009 — a listagem/pesquisa de animais propriamente dita está detalhada no UC005 (Incremento 6).
